## DTO
Data Transfert Objects
Leur but est de transmettre les données entre le producteur et le consommateur.
Utilisé au niveau du contrôleur typiquement :
	- transféré les données au modèle
	- transféré les données au client
Le besoin client est souvent différent du besoin de persistence.
Les DTOs peuvent être optimisés pour la sérialisation et la déserilalisation.
